# Edu Revolution — CSE 111 Website Project

A responsive educational website made with **HTML, CSS, and JavaScript**.

## Project files
- `index.html` — website structure and content
- `style.css` — layout, colours, responsive design, and styling
- `script.js` — mobile navigation, course search, demo course buttons, and contact form interaction

## How to run
1. Download and extract `Edu_Revolution_CSE111.zip`.
2. Open the extracted folder.
3. Double-click `index.html` to open the website in a browser.

You can also open the folder in Visual Studio Code and use the Live Server extension.

## Features
- Responsive homepage and navigation
- Six sample learning paths
- Search/filter courses
- About section
- Contact form with front-end validation and demo confirmation
- Mobile-friendly menu

## Technologies used
- HTML5
- CSS3
- JavaScript (vanilla)

## Customisation
Edit the course cards in `index.html` to change course names and descriptions. Update colours and spacing in `style.css`. Add real registration or contact functionality by connecting a backend; the current form is only a front-end demonstration.

## Academic note
This is a starter project for CSE 111. Add your name, registration number, course/section, and any requirements given by your instructor before submission. Make sure you understand the code and can explain each section.
